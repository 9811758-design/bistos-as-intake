# Bistos A/S 접수 관리

Google Sheets의 `2026 국내 서비스 접수/처리 내역` 탭과 연결되는 Windows 접수 프로그램입니다. 신규 접수는 A:AJ 전체 열 형식으로 최상단에 추가되고, 검색 결과를 불러온 뒤 저장하면 같은 행을 덮어씁니다.

## 처음 한 번 설정

1. Google Cloud에서 Google Sheets API를 사용 설정합니다.
2. OAuth 동의 화면을 설정하고 데스크톱 앱 유형의 OAuth 클라이언트 JSON을 내려받습니다.
3. 프로그램을 처음 실행해 OAuth 클라이언트 JSON과 기본 접수자 이름을 선택합니다.
4. Chrome에서 Google 계정으로 로그인하고 시트 접근을 허용합니다.

OAuth 클라이언트 JSON은 프로그램에 포함되지 않으며 `%LOCALAPPDATA%\Bistos\ASIntake\config.json`에는 파일 위치만 저장됩니다. 로그인 토큰은 같은 폴더의 `google-oauth-token.json`에 저장되어 다음 실행부터 자동 로그인됩니다. 두 파일을 메일로 보내거나 저장소에 올리지 마세요.

## 사용법

- 신규 접수: `새 접수`에서 내용을 입력하고 `신규 저장`을 누릅니다. 접수번호는 `DSYYMMDDNN` 형식으로 자동 생성됩니다.
- 처리자: 저장 시 처리자는 항상 `장진영`으로 입력됩니다.
- 보증판정: 생산일 기준으로 자동 계산됩니다. `BT700`, `BT200`, `BT220`은 1년, 그 외 모델은 2년 보증으로 판정합니다.
- 검색: 연도와 검색어를 입력합니다. 서비스번호, 의뢰자, 병원, 모델, 시리얼, 증상에서 찾습니다.
- 수정: 검색 결과를 선택해 `검색 결과 불러오기`를 누르고 수정한 뒤 `기존 행 덮어쓰기`를 누릅니다.
- 해결 추천: 모델과 증상 또는 불량원인을 입력한 뒤 `해결 추천`을 누릅니다. 과거 처리 이력에서 유사 사례 5건을 찾아 보여주며 `대응조치만 적용` 또는 `원인·조치 적용`을 선택할 수 있습니다.
- 추천 학습: 적용한 해결 조합은 원문 대신 익명 해시와 적용 횟수만 PC에 누적되며 다음 추천 순위에 반영됩니다.
- 미처리 경고: 접수 후 7일이 지난 미처리 건은 프로그램 안에서 경고 목록으로 확인할 수 있습니다.
- 대시보드: 날짜 구간을 지정해 미처리 현황, 모델별 반복 고장, 월별 불량원인 통계를 확인할 수 있습니다.
- Google 시트에서 직접 수정해도 됩니다. 프로그램과 시트 중 마지막에 저장한 내용이 최종값입니다.

해결 추천은 Google 시트 기록을 PC 안에서 비교하며 외부 AI 서비스로 고객·병원·장비 정보를 보내지 않습니다. 추천 내용은 과거 사례를 참고한 값이므로 저장 전에 담당자가 최종 확인하세요.

## 개발 실행과 빌드

```powershell
uv run as-intake --demo
uv run as-intake
.\build_as_intake.ps1
```

빌드 결과는 `dist\BistosASIntake.exe`입니다. 실제 Google 시트 연결에는 외부 OAuth 클라이언트 JSON이 필요합니다.
